# FlavorHaus-Demo-Bilder

Diese Bilder gehören **nicht** zur App (sie werden nicht gebaut). Sie dienen dazu, die FlavorHaus-Demo
über das Admin-Panel wiederherzustellen. Alle Formate werden vom Backend akzeptiert (JPEG, PNG, WebP)
und beim Hochladen automatisch verkleinert.

| Datei | Wo im Admin-Panel hochladen |
|---|---|
| `logo.png` | Website → Allgemein → Logo |
| `hero.webp` | Website → Startseite → Bild oben |
| `features/feature-1.png` | Website → Startseite → Vorteil 1 (Frische Zutaten) |
| `features/feature-2.png` | Vorteil 2 (Schnelle Lieferung) |
| `features/feature-3.png` | Vorteil 3 (Professioneller Service) |
| `features/feature-4.png` | Vorteil 4 (Parkmöglichkeiten) |
| `categories/<name>.png` | Kategorien → Kategorie bearbeiten → Bild (`pizza`, `pasta`, `burger`, `arabisches`, `salat`, `dessert`, `getraenke`) |
| `dishes/<name>.jpeg` | Gerichte → Gericht bearbeiten → Foto (Dateiname = Gericht, z. B. `pizza_margherita.jpeg`) |

Die vier Icons lagen vorher als SVG vor; das Backend nimmt aus Sicherheitsgründen kein SVG an,
deshalb sind sie hier als PNG (4-fache Größe, transparenter Hintergrund) gespeichert.
